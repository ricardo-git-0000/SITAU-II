# Instrucciones del proyecto

- Respóndeme siempre en español.
- Antes de modificar código, revisa los archivos relacionados.
- No cambies archivos que no estén relacionados con la tarea.
- Ejecuta los tests después de hacer cambios.
- Usa nombres de variables en inglés.
- Mantén el estilo de código existente.
- Si hay varias soluciones, explica brevemente cuál eliges y por qué.
- Cada linea de código que modifiques y/o añadas, no te olvides de comentarlo para que se entienda en el codigo
- Evita realizar compilaciones de codigo de Visual Studio, avisa por texto las tares a compilar para realizarlas yo
